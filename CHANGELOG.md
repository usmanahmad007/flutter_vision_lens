## 0.1.0

* Initial release of `flutter_vision_lens`.
* Added interactive `VisionLensOverlay` with Tap-to-Inspect, Freehand Lasso, and Bounding Box selection.
* Added animated Apple Visual Intelligence neon shimmering glow and spotlight dimming shaders.
* Added `VisionLensController` for reactive state management and object tracking.
* Added `VisionCropEngine` for precise coordinate mapping between screen views and underlying images.
* Added `VisionAiAdapter` base with built-in `MockVisionAdapter` for offline zero-config testing.
* Added `GeminiVisionAdapter` for seamless Google Gemini multimodal AI integration.
* Added `VisionLensResultSheet` modern floating response card with action buttons.
* Full multi-platform support across Android, iOS, Web, macOS, Windows, and Linux.
